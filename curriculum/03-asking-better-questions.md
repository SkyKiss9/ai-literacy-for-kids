# Lesson 3: Asking Better Questions

## Goal

Students learn that clearer questions often lead to more useful answers.

## Time

30-45 minutes

## Materials

- Paper for drafting questions
- Teacher-controlled AI tool

## Warm-Up

Compare:

- Tell me about animals.
- Explain why penguins cannot fly in a way a 9-year-old can understand.

Ask which question is clearer and why.

## Demonstration

Show how AI answers change when the question includes:

- topic
- audience
- purpose
- format

## Activity

Students rewrite a vague question into a clearer one using this pattern:

```text
Please explain ____ for a ____ in ____ short steps.
```

## Safety Moment

Clear questions do not need private details. We can be specific without sharing personal information.

## Reflection

Complete:

```text
A better question includes ____.
```

## Teacher Notes

Praise improvement, not perfection. The lesson is about clarity, not technical prompt engineering.
