# Pilot Feedback

Real-world testing evidence belongs under `docs/pilot-notes/`.

## If You Are A Teacher Or Parent

After a lesson, record:

- age range
- lesson used
- what worked
- what confused students
- what safety reminder had to be repeated
- one concrete revision for next time
