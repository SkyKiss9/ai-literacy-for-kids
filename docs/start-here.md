# Teacher Quickstart

If you want to use the project this week, start here.

## First Pilot Path

1. Read `guides/teacher-starter-pack.md`
2. Read `curriculum/01-what-is-ai.md`
3. Print `worksheets/my-ai-safety-rules.md`
4. Run one 30-45 minute lesson
5. Record feedback in `guides/classroom-trial-feedback-template.md`

## Before Class

- one adult-controlled AI account
- one backup source for answer-checking
- a printed worksheet or notebook version
- a privacy reminder ready to say out loud

## Best Lessons To Start With

- Lesson 1: What Is AI?
- Lesson 2: AI Can Help, But It Can Be Wrong
