## What This Project Is

AI Literacy for Kids is a bilingual open-source curriculum project for children ages 7-12. It helps teachers, parents, and community educators introduce AI in a safe, practical, and critical-thinking-centered way.

## Current Best First Pilot

Use Lesson 1 or Lesson 2 first.

- Lesson 1 teaches what AI is.
- Lesson 2 teaches that useful-sounding answers still need checking.
