# Pilot Notes

Store real classroom, family, workshop, or volunteer trial evidence here.

## What Belongs Here

- classroom trial notes
- family-use feedback
- teacher timing observations
- confusing prompt examples
- safety issues discovered in real use
- revision decisions based on actual testing

## File Naming

Use this shape:

```text
YYYY-MM-DD-short-context.md
```

Examples:

- `2026-06-15-grade4-library-club.md`
- `2026-06-18-home-pilot-parent-feedback.md`

## Minimum Note Structure

- context
- age range
- lesson used
- what worked
- what confused students
- what safety reminder was needed
- one concrete revision for next time
