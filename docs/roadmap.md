# Roadmap

## Mission

Build a publicly reusable, child-safe, bilingual AI literacy curriculum that can be adopted by teachers, parents, and community educators.

## Phase 1: Public Starter Kit

Status: in progress

Goals:

- complete eight lesson drafts
- provide teacher and parent guides
- provide printable worksheets
- keep English and Chinese materials paired
- enforce basic repository quality with scripts and CI

Success signals:

- an external educator can understand the repository without private explanation
- a contributor can open a safe content PR using repository docs alone
- a maintainer can validate structure with one command

## Phase 2: Pilot Readiness

Planned additions:

- lesson-by-lesson printable worksheets
- classroom timing notes based on real use
- feedback summaries from teachers and parents
- child-safe prompt examples for reading, writing, and science

Success signals:

- at least 3 documented classroom or home trials
- feedback-driven revisions to unclear lessons
- clearer differentiation for ages 7-9 and 10-12

## Phase 3: Maintained Public Infrastructure

Planned additions:

- translation contributions beyond English and Chinese
- release notes for curriculum updates
- educator onboarding checklist
- downloadable teacher packet exports

Success signals:

- repeat contributors
- real issue triage from outside users
- public evidence of reuse, such as school clubs, parent workshops, or volunteer programs

## What Evidence We Still Need

This repository can honestly claim public educational value now, but it still needs stronger external proof of adoption. The most useful future evidence is:

- classroom pilot notes
- teacher and parent testimonials
- forks, stars, translations, or adaptation examples
- links to real usage in community programs

## Maintainer Priorities

1. protect child safety and privacy in all examples
2. improve practical usability for non-technical adults
3. keep bilingual files aligned
4. convert vague intentions into reusable teaching assets
