# AI Literacy for Kids

Open-source AI literacy materials for elementary school students, teachers, and parents.

This project helps children learn how to use AI as a tool for learning, asking better questions, thinking more clearly, and understanding the world responsibly.

中文说明：[README.zh-CN.md](README.zh-CN.md)

## Mission

AI should not only be available to adults, engineers, or companies. Children also need age-appropriate guidance so they can understand what AI can do, what it cannot do, and how to use it safely.

This repository provides free teaching materials for elementary school AI literacy:

- Short lesson plans for children ages 7-12
- Teacher and parent guides
- Classroom activities and worksheets
- AI safety and critical-thinking rules
- Prompt examples for reading, writing, science, and everyday curiosity
- Bilingual materials in English and Chinese

## Who This Is For

- Elementary school teachers who want practical AI literacy lessons
- Parents who want to help children use AI safely
- Volunteers running community education programs
- Open-source contributors interested in education and child-safe AI

## Project Status

This is an early-stage open-source project. The goal is to build a reusable curriculum that can be freely adapted by schools, families, and community groups.

The first milestone is a small but complete starter curriculum:

- 8 introductory lessons
- Teacher guide
- Parent guide
- Safety rules for children
- Printable classroom worksheets
- Feedback template for classroom trials
