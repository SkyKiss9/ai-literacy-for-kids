# Security Policy

This repository is primarily educational content, but security and safety still matter because the materials are intended for use with children.

## What To Report

Please report issues such as:

- guidance that could expose private child information
- prompts that encourage unsafe behavior
- misleading claims that may create safety risk in classroom or home use
- repository automation that leaks data or behaves unexpectedly

## How To Report

Open a GitHub issue only if the concern can be discussed safely in public.

If the issue involves unsafe child-facing content that should not remain public, contact the maintainer privately first and describe:

- the affected file
- the risky wording or behavior
- why it is unsafe
- a safer replacement, if known

## Scope

This policy covers:

- educational guidance in `curriculum/`, `guides/`, and `worksheets/`
- repository tooling in `scripts/`
- CI configuration in `.github/`
