# Lesson 3 Teacher Packet

This packet helps a teacher run `Lesson 3: Asking Better Questions` with minimal setup.

## Packet Includes

- core lesson: `curriculum/03-asking-better-questions.md`
- prompt practice sheet: `worksheets/better-questions.md`
- safety reference: `guides/child-ai-safety.md`
- trial feedback capture: `guides/classroom-trial-feedback-template.md`

## What To Prepare

- one adult-controlled AI account
- paper for students to rewrite questions
- one example of a vague prompt and one example of a clearer prompt

## Suggested Demonstration

Compare these two prompts:

```text
Tell me about animals.
```

```text
Explain why penguins cannot fly in a way a 9-year-old can understand, in 3 short steps.
```

## What Students Should Notice

- the clearer prompt gives a narrower answer
- audience matters
- format matters
- clarity does not require personal information

## Exit Prompt

```text
A better question includes ____.
```

## Best Revisions After The Lesson

- make one prompt example shorter
- replace one abstract term with simpler language
- record the most common student question pattern
