# Teacher Starter Pack

This pack is for a teacher who wants to try the repository in a real class this week without reading every file first.

## Best First Pilot

Run one short lesson before attempting a broader rollout.

Recommended first sequence:

1. Read `guides/teacher-guide.md`
2. Read `curriculum/01-what-is-ai.md`
3. Print or copy `worksheets/my-ai-safety-rules.md`
4. Use one adult-controlled AI account
5. Record feedback with `guides/classroom-trial-feedback-template.md`

## Minimum Setup

- One adult-controlled AI account
- One internet-connected device
- Optional projector
- Paper for student questions
- One trusted source for answer-checking

## 30-45 Minute Pilot Structure

### Before class

- Read the lesson once
- Prepare one simple teacher prompt
- Review the no-private-data rule
- Choose one backup source for verification

### During class

- 5 min: warm-up discussion
- 10 min: teacher demonstration
- 10 min: student question activity
- 10 min: answer-checking and safety discussion
- 5 min: reflection

### After class

- Record what students understood quickly
- Note confusing language
- Note whether privacy reminders were strong enough
- Save one concrete revision for the next run

## What Success Looks Like

After one pilot, you should be able to answer:

- Was the lesson understandable for the target age?
- Did the timing work?
- Did students grasp that AI can be wrong?
- Which safety reminder had to be repeated?

## Common Concerns

### Do students need their own accounts?

No. Early lessons should use one adult-controlled account.

### What if the AI gives a poor answer?

Use that as part of the lesson. It creates a natural opening for checking and doubt.

### What if students ask personal or sensitive questions?

Pause and redirect. Personal, medical, legal, or family-conflict questions should go to a trusted adult, not the AI tool.
