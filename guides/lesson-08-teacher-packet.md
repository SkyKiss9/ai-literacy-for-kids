# Lesson 8 Teacher Packet

This packet helps a teacher run `Lesson 8: Building My Personal AI Safety Rules` as the closing reflection lesson.

## Packet Includes

- core lesson: `curriculum/08-building-my-personal-ai-safety-rules.md`
- safety worksheet: `worksheets/my-ai-safety-rules.md`
- safety reference: `guides/child-ai-safety.md`
- trial feedback capture: `guides/classroom-trial-feedback-template.md`

## What To Prepare

- one printed worksheet per student or notebook version
- pens or pencils
- one board or poster space for class rules

## Suggested Demonstration

Review the course habits:

- ask clearly
- check answers
- protect privacy
- use AI honestly
- ask an adult when something is serious

Then model turning one habit into a short personal rule.

## What Students Should Notice

- rules can be short and still useful
- safety rules should be easy to remember
- personal wording helps ownership

## Good Exit Prompt

```text
One AI rule I want to remember is ____.
```

## Best Post-Lesson Revisions

- simplify any rule that sounds too adult or abstract
- collect the most repeated student rules
- note which course idea was remembered most strongly
